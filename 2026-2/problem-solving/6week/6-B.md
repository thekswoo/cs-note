# 경로 우회

**유형**: 방향 그래프 BFS

**핵심**: 1번에서 BFS, 공사 노드는 큐에 안 넣음 → 꺼낸 노드의 `adj`가 비어 있으면 YES

**주의**
- `adj`는 공사 여부 상관없이 입력 그대로 (외곽 = 원래 out-degree 0)
- `adj` 크기는 `n + 1`
- `visited`는 push할 때 체크

```cpp
q.push(1); visited[1] = 1;
while (!q.empty()) {
    int cur = q.front(); q.pop();
    if (adj[cur].empty()) { cout << "YES\n"; return; }
    for (int nxt : adj[cur])
        if (!gongsa[nxt] && !visited[nxt]) {
            visited[nxt] = 1;
            q.push(nxt);
        }
}
cout << "NO\n";
```
