# 유도등

**유형**: 수학 (포함-배제)

**핵심**: A의 배수 개수 + B의 배수 개수 - 둘 다의 배수(lcm의 배수) 개수 → `n/a + n/b - n/lcm(a,b)`

**주의**
- N ≤ 10^18 → `long long` 필수
- lcm 직접 구현 시 `a / gcd(a,b) * b` 순서로 (`a*b` 먼저 하면 오버플로우 위험)
- `std::lcm`, `std::gcd`는 C++17부터

```cpp
ll a, b, n;
cin >> a >> b >> n;
cout << n/a + n/b - n/lcm(a, b) << '\n';
```
