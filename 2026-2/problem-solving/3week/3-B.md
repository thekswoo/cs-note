# 창고 순회

**유형**: 분할 정복 (재귀)

**핵심**: 2^N 격자를 4등분 → (r, c)가 속한 사분면 번호 k(0~3)만큼 앞 구역 칸 수 `k * half * half`를 더하고, 그 사분면 안 좌표로 재귀 → `n == 0`이면 1

**주의**
- 입력이 1-indexed → `func(n, r - 1, c - 1)`로 0-indexed 변환
- 오른쪽/아래 사분면으로 갈 때 좌표에서 `half`를 빼줘야 함
- N ≤ 15 → 최대 4^15 = 2^30 이라 `int`로 가능
- 시간복잡도 O(N) (재귀 깊이 N)

```cpp
int func(int n, int r, int c) {
    if (n == 0) return 1;
    int half = 1 << (n - 1);
    if (r < half && c < half)  return func(n - 1, r, c);
    if (r < half && c >= half) return half * half + func(n - 1, r, c - half);
    if (r >= half && c < half) return 2 * half * half + func(n - 1, r - half, c);
    return 3 * half * half + func(n - 1, r - half, c - half);
}
```
