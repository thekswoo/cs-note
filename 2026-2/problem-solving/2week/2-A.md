# 과일 판매

**유형**: 종류별 queue (FIFO 시뮬레이션)

**핵심**: 과일 종류마다 queue 하나 → 입고는 `push`, 출고는 `front` 더하고 `pop`

**주의**
- 출고 전에 `empty()` 체크 → 비어 있으면 요청 무시 (빈 queue `front()`는 **런타임 에러**)
- 종류 번호가 1~M이라 크기는 `M + 1` (여기선 최대 50이라 `51`로 고정)
- `cmd == 1`이면 가격 입력이 **없음** → `p`만 읽기
- 테스트 케이스마다 queue, `sum` 새로 선언 (초기화 누락 주의)
- 합 최대 50만 × 100 = 5천만 → `int` OK
- 안쪽 `int m`이 바깥 `m`(종류 수)을 가림 → 동작은 하지만 헷갈리니까 이름 다르게

```cpp
vector<queue<int>> q(m + 1);
int sum = 0;

for (int i = 0; i < n; i++) {
    int cmd, p;
    cin >> cmd >> p;
    if (cmd == 0) {
        int price; cin >> price;
        q[p].push(price);
    } else {
        if (q[p].empty()) continue;
        sum += q[p].front();
        q[p].pop();
    }
}
cout << sum << '\n';
```
