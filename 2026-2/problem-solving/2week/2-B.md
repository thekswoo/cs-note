# 부스 탐방

**유형**: 그리디 + priority_queue (max-heap)

**핵심**: 일단 전부 방문 → 마일리지가 음수가 되면 **지금까지 방문한 것 중 제일 비싼 음수 부스** 하나 취소

**주의**
- 음수 부스는 `cur`과 상관없이 **항상** pq에 기록 → 조건부로 넣으면 나중에 못 되돌림 (오답 4 나옴)
- `priority_queue<int>`는 max-heap → 비용을 `-a`(양수)로 넣어야 top이 제일 비싼 부스
- 취소는 `if` 한 번이면 충분 (top ≥ 이번 비용 → 직전 `cur` 이상으로 회복)
- 취소할 때 `cnt--` 잊지 말기
- 합 최대 8만 × 1000 = 8천만 → `int` OK

```cpp
priority_queue<int> pq;
int cnt = 0, cur = 0;

for (int i = 0; i < n; i++) {
    int a; cin >> a;
    cur += a;
    cnt++;
    if (a < 0) pq.push(-a);

    if (cur < 0) {
        cur += pq.top();
        pq.pop();
        cnt--;
    }
}
cout << cnt << '\n';
```
