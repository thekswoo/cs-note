# 부품 벨트

**유형**: 커서 에디터 → deque 2개 (`left` | 커서 | `right`)

**핵심**: 커서에 닿아 있는 건 `left.back()`, `right.front()` → 모든 연산이 이 두 곳에서만 일어나서 O(1)

| 연산 | 동작 |
|---|---|
| `L` | `left.back()` → `right.push_front()` |
| `D` | `right.front()` → `left.push_back()` |
| `B` | `left.pop_back()` |
| `C` | `swap(left.back(), right.front())` |
| `P c` | `left.push_back(c)` |

**주의**
- 커서 쪽은 `left.back()` / `right.front()` → `front`/`back` 헷갈리면 순서 꼬임
- `front()`/`back()` 전에 `empty()` 체크 필수 → 빈 deque 접근은 **런타임 에러**
- `P`는 `left`에 넣기 (새 커서 = 끼운 부품 오른쪽)
- 시작 커서는 맨 왼쪽 → 문자열 전부 `right`에
- 남은 게 없으면 `EMPTY` 출력

```cpp
deque<char> left, right(s.begin(), s.end());

if (opt == 'L') {
    if (left.empty()) continue;
    right.push_front(left.back()); left.pop_back();
}
else if (opt == 'D') {
    if (right.empty()) continue;
    left.push_back(right.front()); right.pop_front();
}
else if (opt == 'B') { if (!left.empty()) left.pop_back(); }
else if (opt == 'C') {
    if (!left.empty() && !right.empty()) swap(left.back(), right.front());
}
else if (opt == 'P') { char c; cin >> c; left.push_back(c); }
```

### string → deque
- `deque<char> dq(s.begin(), s.end());` (생성자)
- `dq.assign(s.begin(), s.end());` (덮어쓰기)
- `dq.insert(dq.end(), s.begin(), s.end());` (뒤에 붙이기)
- range-for에 빨간줄 → 코드 문제 아님, IntelliSense C++ 표준 버전 확인 (C++11 이상)
