# 데이터셋 다운로드

**유형**: DP (0/1 배낭)

**핵심**: `dp[i][w]` = i번째 데이터셋까지 고려, 용량 w 이하일 때 최대 상승치 → 안 고르면 `dp[i-1][w]`, 고르면 `dp[i-1][w-c] + a` 중 최댓값

**주의**
- 입력 순서가 `A C`(상승치, 용량) 순
- 각 데이터셋은 한 번만 → 반드시 `i-1` 행에서 가져옴
- 2차원 dp는 5001 × 5001 int ≈ 100MB (제한 256MB라 통과). 1차원으로 줄이려면 w를 **역순**으로 순회
- 시간복잡도 O(N·X)

```cpp
vector<vector<int>> dp(N + 1, vector<int>(X + 1, 0));
for (int i = 1; i <= N; i++) {
    int a, c; cin >> a >> c;
    for (int w = 0; w <= X; w++) {
        dp[i][w] = dp[i - 1][w];
        if (w >= c) dp[i][w] = max(dp[i][w], dp[i - 1][w - c] + a);
    }
}
cout << dp[N][X] << '\n';
```
