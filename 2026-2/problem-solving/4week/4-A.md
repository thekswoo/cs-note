# 배송 허브

**유형**: 트리 DFS (스택)

**핵심**: 부모 배열로 `child` 리스트 구성 → 루트에서 DFS, X는 스택에 안 넣음 → X를 뺀 자식 수가 0인 노드를 말단으로 카운트

**주의**
- 루트가 항상 0번이 아님 → 입력에서 `-1`인 노드를 루트로 저장
- `X == root`면 바로 0 출력
- 자식이 X 하나뿐인 노드는 X가 빠지면서 말단이 됨 → 자식 수는 X를 제외하고 셈
- N ≤ 100,000 → 재귀 DFS는 스택 오버플로우 위험, 명시적 `stack` 사용

```cpp
if (X == root) { cout << "0\n"; return; }
int leaf = 0;
stack<int> st; st.push(root);
while (!st.empty()) {
    int v = st.top(); st.pop();
    int cnt = 0;
    for (int c : child[v]) {
        if (c == X) continue;
        cnt++;
        st.push(c);
    }
    if (cnt == 0) leaf++;
}
cout << leaf << '\n';
```
