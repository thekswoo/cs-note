# 배터리 충전

**유형**: 그리디 + 카운팅 정렬

**핵심**: 기기 i를 1분씩 충전할 때 얻는 양은 `b`가 `(100-a)/b`번, 그다음 자투리 `(100-a)%b`가 1번 (증가량이 줄어들기만 함) → 모든 1분 단위 증가량 중 큰 것부터 N개 고르면 최적. 값이 1~100이라 `cnt[값]`으로 세서 100부터 내려가며 가져감

**주의**
- 시작 답은 `a`의 총합
- 1분 증가량 개수가 최대 100 × M = 2,000만이라 pq에 하나씩 넣으면 느림 → 카운팅으로 O(100 + M)
- `min(n, cnt[i])` 인자 타입 같아야 함 → 둘 다 `ll`
- 이미 100%인 기기는 자투리 0이 `cnt[0]`에 들어가는데, 루프가 `i >= 1`까지라 무시됨
- 증가량 총 개수보다 N이 클 수 있음 → `n > 0` 조건으로 남는 시간은 버림

```cpp
ll cnt[101] = {0};
for (int i = 0; i < m; i++) {
    int need = 100 - a[i];
    cnt[b[i]] += need / b[i];
    cnt[need % b[i]]++;
}
for (int i = 100; i >= 1 && n > 0; i--) {
    ll take = min(n, cnt[i]);
    ans += take * i;
    n -= take;
}
```

**실수 (5-A-pq.cpp)**
- 벡터 크기를 `a(N), b(N)`으로 잡음 → 기기 수는 `M`이라 M > N이면 범위 밖 접근. `a(M), b(M)`으로 수정
- `while(N--)`만 쓰고 pq가 비었는지 확인 안 함 → 증가량 개수보다 N이 크면(예: 모두 100%인 기기) 빈 pq에서 `top()` 호출(UB). `while(N-- && !pq.empty())`로 수정
