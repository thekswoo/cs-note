# 난방

**유형**: 다익스트라

**핵심**: 1번에서 다익스트라 → `dist[N]` 출력. 최소 힙에서 꺼낸 거리가 `dist[u]`보다 크면 이미 처리된 낡은 정보라 스킵

**주의**
- 양방향 간선 → `adj[u]`, `adj[v]` 둘 다 추가
- `adj`, `dist` 크기는 `n + 1`
- 최대 거리 1e5 × 1e4 = 1e9 → `int` 경계라 `dist`는 `ll`, `INF = 1e18`
- 최소 힙: `priority_queue<pair<ll,int>, vector<pair<ll,int>>, greater<>>` (또는 기본 pq에 거리 음수로 넣기)
- N번을 pq에서 꺼낸 순간 최단 거리 확정 → 바로 `break` 가능

```cpp
vector<ll> dist(n + 1, INF);
dist[1] = 0; pq.push({0, 1});
while (!pq.empty()) {
    auto [d, u] = pq.top(); pq.pop();
    if (d > dist[u]) continue;
    if (u == n) break;
    for (auto &[v, w] : adj[u])
        if (dist[u] + w < dist[v]) {
            dist[v] = dist[u] + w;
            pq.push({dist[v], v});
        }
}
cout << dist[n] << '\n';
```
