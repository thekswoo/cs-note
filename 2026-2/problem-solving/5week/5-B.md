### 다익스트라
시작 정점으로부터의 거리를 구하는 알고리즘

### 필요 배열
- `vector<vector<pair<int,int>>> adj(n+1)` : 정점 인접 리스트
- `vector<ll> dist(n+1,INF)` : i정점까지 임시 최소 거리 저장 배열
- `priority_queue<pair<ll,int>, vector<pair<ll,int>>, greater<>> pq` : 인접 정점 중 가장 작은 거리 조회용 우선순위 큐

### 핵심 로직

```c++
while(!pq.empty()) {
    auto cur = pq.top();
    pq.pop();
    auto d = cur.X; // cur 정점까지 거리
    auto u = cur.Y; // cur 정점 번호
        
    if(d > dist[u]) continue; // 이미 임시 거리 배열이 더 작은 경우 continue
    if(u == n) break; // top() 정점이 끝 정점인 경우 끝

    for(auto &e : adj[u]){ // top() 정점의 인접 정점 순회해서 인접 정점까지 거리가 더 짧은 경우 갱신
        int v = e.X;
        int w = e.Y;

        if(dist[u] + w < dist[v]) {
            dist[v] = dist[u] + w;
            pq.push({dist[v],v});
        }
    }
}
```
